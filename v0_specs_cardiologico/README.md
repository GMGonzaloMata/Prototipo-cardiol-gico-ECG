# Specs — Prototipo v0

## Objetivo
Construir una maqueta navegable de baja fidelidad para validar con el referente institucional el flujo principal del sistema.

El prototipo **no debe implementar backend real, pipeline real ni modelo de IA real**. Todos los pacientes, episodios y resultados predictivos deben ser simulados.

## Alcance del prototipo
El flujo principal debe ser:

1. Inicio / Dashboard
2. Procesamiento simulado
3. Lista de episodios clínicos
4. Detalle de episodio
5. Resultado predictivo simulado de HVI
6. Cuarentena

## Usuario principal
Profesional médico del Instituto de Cardiología de Corrientes.

## Principios
- Interfaz simple y clínica.
- Evitar jerga técnica innecesaria.
- No mostrar datos personales reales.
- Diferenciar claramente datos clínicos, predicciones y advertencias.
- Toda predicción debe estar marcada como simulada.
- El sistema es de apoyo a la decisión, no de diagnóstico autónomo.

## Prioridad
El objetivo del v0 es validar:
- navegación;
- jerarquía de información;
- pantallas necesarias;
- comprensión del flujo;
- presentación del resultado predictivo.
