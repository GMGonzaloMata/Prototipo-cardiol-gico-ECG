# Lineamientos visuales

## Estilo general
Interfaz clínica, sobria, clara y moderna.

Evitar:
- estética futurista exagerada;
- demasiados gradientes;
- efectos 3D;
- dashboards excesivamente cargados;
- terminología técnica visible para el médico.

## Layout
- Sidebar izquierda.
- Header simple.
- Contenido principal con ancho cómodo.
- Tarjetas para resúmenes.
- Tablas para episodios y cuarentena.

## Jerarquía
Priorizar:
1. estado del episodio;
2. estudios disponibles;
3. resultado predictivo;
4. probabilidad;
5. advertencias.

## Estados visuales
Usar badges para:
- Apto para análisis
- Incompleto
- En revisión
- Disponible
- No disponible
- Simulado

## Accesibilidad
- Buen contraste.
- Tipografía legible.
- Tamaños de texto cómodos.
- No depender únicamente del color para indicar estados.

## Branding
No es necesario reproducir identidad gráfica oficial del Instituto en esta primera versión.
Puede utilizarse un nombre neutro como:

**Sistema de Apoyo Cardiológico**

Subtítulo:
**Prototipo v0**
