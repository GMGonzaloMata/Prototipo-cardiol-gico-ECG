# Criterios de aceptación del prototipo

El prototipo se considera listo para validación cuando:

1. Existe navegación completa entre Inicio, Procesamiento, Episodios y Cuarentena.
2. Desde Episodios se puede abrir el detalle de al menos un episodio.
3. Desde el detalle se puede navegar a un resultado predictivo simulado.
4. El resultado de HVI muestra clasificación, probabilidad y métricas ficticias.
5. Todas las predicciones están claramente identificadas como simuladas.
6. No aparece ningún dato personal real.
7. El usuario puede reconocer qué estudios componen un episodio.
8. Se visualiza la relación temporal entre estudios.
9. La pantalla de procesamiento muestra resultados sintéticos del pipeline.
10. La cuarentena muestra motivos comprensibles para un usuario no técnico.
11. La navegación es consistente y no requiere backend real.
12. La interfaz permite que el referente evalúe si el flujo representa correctamente el uso esperado.
