# Lineamientos visuales

## Estilo
Interfaz médica, limpia, sobria y moderna.

## Prioridad
La interfaz debe responder inmediatamente estas preguntas:

1. ¿Qué ECG se está analizando?
2. ¿Terminó el análisis?
3. ¿Qué indica sobre HVI?
4. ¿Cuál es el potasio estimado?
5. ¿Qué tan confiable es la predicción?
6. ¿Está claro que es una simulación?

## Layout
- navegación simple;
- contenido centrado;
- tarjetas grandes para resultados;
- pocos elementos por pantalla.

## Colores
Utilizar estados visuales moderados:
- normal;
- atención;
- resultado positivo;
- información.

No depender únicamente del color.

## Tipografía
Legible y profesional.

## Evitar
- dashboards con muchas métricas;
- estética futurista;
- exceso de gráficos;
- datos técnicos de infraestructura;
- pantallas de administración;
- exceso de menús.
