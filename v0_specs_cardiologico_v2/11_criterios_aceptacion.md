# Criterios de aceptación

El prototipo está listo para validación cuando:

1. El usuario puede iniciar un nuevo análisis desde la pantalla inicial.
2. Puede simular la carga de un ECG.
3. Puede revisar visualmente el ECG antes de analizarlo.
4. Puede iniciar el análisis.
5. Se muestra un estado de procesamiento comprensible.
6. El procesamiento conduce a una pantalla de resultados.
7. Se muestra un resultado simulado para HVI.
8. Se muestra la probabilidad asociada a HVI.
9. Se muestra un nivel estimado de potasio.
10. Se muestra una clasificación simple del potasio.
11. HVI y potasio aparecen juntos en la misma pantalla.
12. Los resultados están identificados claramente como simulados.
13. Existe una advertencia de apoyo a la decisión clínica.
14. No aparecen datos personales reales.
15. El usuario puede iniciar un nuevo análisis.
16. No se muestra el pipeline de anonimización como parte del flujo clínico principal.
